# LAS采集约定

文件使用UTF-8，行尾可LF或CRLF。LAS2.0条目按首个点分助记符、点后到首空白为单位、其后到首冒号为值，冒号之后为说明；参数无单位时仍保留点后空白。以#起头的整行是注释，数据行不支持尾部注释。~ASCII之后数字按Curve段列序排列，~Other等新段结束当前数据区。

NULL按原数值Decimal比较，不先换单位；深度NULL使文件正式索引无法完成。记录序号含重复深度，标准深度用显式正scale与offset转换；查询按(标准深度,run_id,原记录序号)排序。跨井必须显式选择，不能仅因window相同混入另一井。原始字节区间含每个数字token对应区段，并保留物理行号；编码变更会改变SHA而使旧索引失效。

domain只清点物理行，不解析Curve段或建立深度索引。
